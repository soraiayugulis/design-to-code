# Phase 5: Git Operations & PR Creation - TDD Scenarios

## Test Scenarios

### Test: Create feature branch from current HEAD
**Given**: Repository on main branch
**When**: GitOperations.createBranch() is called with branch name "feature/ai-gen-abc123"
**Then**: New branch should be created
**And**: Current HEAD should point to new branch

```kotlin
@Test
fun `should create feature branch from current HEAD`() {
    val git = Git.init().setDirectory(tempDir).call()
    git.commit().setMessage("Initial commit").call()
    
    GitOperations.createBranch(git, "feature/ai-gen-abc123")
    
    val branch = git.repository.findRef("refs/heads/feature/ai-gen-abc123")
    assertNotNull(branch)
}
```

### Test: Commit generated code changes
**Given**: Feature branch checked out
**And**: Generated code files in workspace
**When**: GitOperations.commitChanges() is called with commit message
**Then**: Changes should be staged and committed
**And**: Commit should have specified message

```kotlin
@Test
fun `should commit generated code changes`() {
    val git = setupGitRepository(tempDir)
    GitOperations.createBranch(git, "feature/ai-gen-abc123")
    git.checkout().setName("feature/ai-gen-abc123").call()
    
    // Create generated files
    val controllerFile = File(tempDir, "src/main/kotlin/UserController.kt")
    controllerFile.writeText("generated code")
    
    GitOperations.commitChanges(git, "feat(auto-gen): implementation for updated specifications")
    
    val commit = git.log().setMaxCount(1).call().first()
    assertEquals("feat(auto-gen): implementation for updated specifications", commit.fullMessage)
}
```

### Test: Create Pull Request via GitHub CLI
**Given**: Feature branch with committed changes
**And**: GitHub token available
**When**: GitOperations.createPullRequest() is called
**Then**: PR should be created on GitHub
**And**: PR should point from feature branch to main
**And**: PR should have specified title and body

```kotlin
@Test
fun `should create Pull Request via GitHub CLI`() {
    val git = setupGitRepositoryWithChanges(tempDir)
    
    val pr = GitOperations.createPullRequest(
        git = git,
        sourceBranch = "feature/ai-gen-abc123",
        targetBranch = "main",
        title = "🤖 [AI Generated] Implementation for Spec Update",
        body = """
            ## Automated Implementation Report
            This Pull Request was automatically generated by the Design-to-Code AI Pipeline.
            
            ### Validation Summary:
            - **Kotlin Code Generation:** Clean / Hexagonal Architecture standard.
            - **Tests:** JUnit 5 integration tests executed with Testcontainers.
            - **Quality Gate:** 100% Code Coverage verified by Kover/JaCoCo.
        """.trimIndent(),
        githubToken = "test-token"
    )
    
    assertNotNull(pr)
    assertEquals("feature/ai-gen-abc123", pr.sourceBranch)
    assertEquals("main", pr.targetBranch)
}
```

### Test: Handle missing target branch
**Given**: Feature branch created
**And**: Target branch "main" does not exist
**When**: GitOperations.createPullRequest() is called
**Then**: Should throw BranchNotFoundException
**And**: Error should indicate target branch not found

```kotlin
@Test
fun `should handle missing target branch`() {
    val git = setupGitRepository(tempDir)
    GitOperations.createBranch(git, "feature/ai-gen-abc123")
    // Delete main branch to simulate missing target
    git.branchDelete().setBranchNames("main").call()
    
    val exception = assertThrows<BranchNotFoundException> {
        GitOperations.createPullRequest(
            git = git,
            sourceBranch = "feature/ai-gen-abc123",
            targetBranch = "main",
            title = "AI Generated PR",
            body = "PR body",
            githubToken = "test-token"
        )
    }
    
    assertTrue(exception.message!!.contains("main") && exception.message!!.contains("not found"))
}
```
